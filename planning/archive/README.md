# Archived project material

Everything under this directory is retained for historical traceability, not as a current contract. It may contain obsolete URLs, paths, versions, plans, and implementation claims. The canonical maintained documentation is under `docs/`.

- `target-architecture.md` is a proposal, not the current runtime topology.
- `old-api-v0.2.yaml` is the previous incomplete hand-maintained API spec.
- `legacy-project-knowledge/PROJECT_KNOWLEDGE/` and `legacy-guides/` are snapshots from the previous documentation set.
- `old-plans.md`, `ideas.md`, and the retired execution archive preserve older planning notes.
