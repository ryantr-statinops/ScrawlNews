# Project planning archive

This directory separates execution planning from user-facing project documentation. It preserves prior plans, backlog snapshots, and superseded documentation for traceability; none of these files define current runtime behavior. Use `docs/` for the canonical project reference.

- `active-plans/` — former roadmap and implementation plans, retained as historical planning records.
- `tasks/` — prior TODO and in-progress snapshots.
- `docs-roadmap.md` — plan for the previous documentation structure.
- `archive/` — retired plans, target-state proposals, the incomplete earlier API spec, and legacy documentation snapshots.

The archived snapshots may contain stale paths, dates, and implementation claims. They are intentionally not linked from the canonical [docs index](../docs/README.md).
