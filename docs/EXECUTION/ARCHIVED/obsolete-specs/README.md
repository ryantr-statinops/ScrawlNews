# Obsolete Specs

Lưu các **API spec / contract cũ** đã bị thay thế, chỉ để tham khảo lịch sử.

## Quy ước

- Khi `specs/api.yaml` (active, tại `EXECUTION/ACTIVE_PLANS/specs/api.yaml`) thay đổi đột phá (breaking change), copy bản cũ vào đây với tên `api-vX.Y.Z.yaml`.
- Không dùng spec trong thư mục này làm căn cứ implement mới.

## Hiện tại

Chưa có spec lỗi thời. Active spec duy nhất là `EXECUTION/ACTIVE_PLANS/specs/api.yaml` (v0.2.0).
