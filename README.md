# ScrawlNews

Automated news aggregation, summarization & delivery agent.

## Skills

| Skill | Technology | Description |
|-------|-----------|-------------|
| **Scrawler** | Playwright | Fetch articles from Google News |
| **Synthesizer** | OpenAI / LLM | Summarize articles into key points |
| **Messenger** | Telegram Bot API | Deliver summaries to Telegram |

## Quick Start

```bash
make install
make run
```

See [SETUP.md](SETUP.md) for detailed instructions.
